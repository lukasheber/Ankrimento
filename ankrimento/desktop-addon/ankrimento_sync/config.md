**sync_folder**: the folder Incremento data is synced through, inside a
folder your sync service keeps in step (Google Drive, Dropbox, iCloud,
OneDrive, Syncthing). Pick it with Tools → Ankrimento Sync. Every device,
including phones running Ankrimento, must use the same folder.

**device_name**: shown to other devices ("Incremento is open on …").
Empty uses the computer's name.
